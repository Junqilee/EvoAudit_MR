# ICLR paper source

This directory tracks the source needed to continue the ICLR 2027 draft. It intentionally excludes generated PDF, log, auxiliary, and SyncTeX files; build those locally with a TeX installation or the Codex LaTeX editor.

The main draft is `main.tex`. Bibliography and ICLR style files are kept beside it so the draft can be opened on another machine without relying on the original parent directory.
