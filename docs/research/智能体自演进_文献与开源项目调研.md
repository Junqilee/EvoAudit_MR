## 0. 什么是"智能体自演进"？

传统 LLM Agent 一旦部署，其架构、提示、记忆、工具集往往**冻结**在专家手工设计的初始状态，难以适应环境变化（新任务、新工具、用户意图漂移）。**自演进智能体（Self-Evolving Agent）**指：智能体在与环境持续交互、获得反馈的过程中，**自主优化自身内部组件**（提示、记忆、工具、工作流、乃至源码与模型参数），从而适应变化、提升性能、走向终身（lifelong）智能体系统。

按"演进发生在哪一层、是否需要训练"，可把现有工作分成一条**递进的能力光谱**：

| 层级 | 演进对象 | 典型信号 | 是否改权重 | 代表工作 |
|---|---|---|---|---|
| L1 行为/提示层 | 单步输出、提示词、反思 | 文本反馈、标量奖励 | 否（推理时） | Reflexion, Self-Refine, OPRO, TextGrad, DSPy |
| L2 经验/记忆层 | 记忆库、技能库、工作流 | 成败轨迹、环境反馈 | 否（检索增强） | Generative Agents, Voyager, ExpeL |
| L3 架构/元层 | Agent 自身代码/拓扑/模块组合 | 元搜索、代码改写 | 视实现（多为无训练的代码搜索） | ADAS, AFlow, AgentSquare, Gödel Agent |
| L4 多体自组织 | 角色、团队结构、协作策略 | 群体反馈、观察者 | 否（生成式编排） | CAMEL, MetaGPT, ChatDev, AgentVerse, AutoAgents, EvoAgent |
| L5 训练驱动层 | 模型/策略参数 | RL 奖励、课程 | 是（微调/RL） | WebRL |

> 两条综述把这一范式概括为从 **MOP → MOA → MAO → MASE**（Manual → Model/Optimizer/Architecture/… → Self-Evolving）的演进。

## 4. 演进时间线（按年份，便于把握脉络）

- **2023**：ReAct(ICLR'23) 奠定基础 → **Reflexion / Self-Refine (NeurIPS'23)** 推理时自我反思 → **Generative Agents (UIST'23)** 记忆反思架构 → **Voyager (NeurIPS'23)** 技能库终身学习 → **CAMEL (NeurIPS'23)** 多智能体 → **MetaGPT / ChatDev / AgentVerse / AutoAgents** 多智能体生成陆续出现。
- **2024**：**OPRO (ICLR'24)** 提示即优化 → **ExpeL (AAAI'24)** 经验学习 → **ADAS / AFlow / AgentSquare / Symbolic Learning / Gödel Agent** 进入"自动设计/自我指涉改写"阶段 → **WebRL (ICLR'25, 投稿于 2024-11)** 训练侧自演化课程 RL。
- **2025**：**AgentSquare / AFlow / ADAS / WebRL / TextGrad(Nature)** 在 ICLR'25 集中亮相；**综合综述**发布；前沿开始关注 **misevolution（误演进）风险**（ICLR'26 *Your Agent May Misevolve*）。
- **2026（截至 08 月）**：进入"自演进系统化与工程化"阶段——**经验/技能外化**（EvolveR, FORGE, Memento-Skills, MARS, ICML'26）、**多智能体自动生成/协同进化**（EvoMAS, SAGE, MetaAgent-X, Skill-MAS, ICML'26）、**RL 驱动跨轮次演进**（RetroAgent）、**开放任务流持续自改进**（Adaptive Auto-Harness）；**误演进(misevolution)** 安全研究成独立方向（ICLR'26 正式录用）。详见第 7 节。

## 5. 关键趋势与开放问题

1. **演进层次上移**：从"调提示/记忆"（L1–L2）到"改架构/改代码"（L3–L4），再到"改权重"（L5），自由度与风险同步上升。
2. **自演进三定律（综述提出，类比阿西莫夫）**：
   - **Endure（安全适应）**：任何修改不得破坏系统安全与稳定；
   - **Excel（性能保持）**：在安全前提下保持/提升任务性能；
   - **Evolve（持续演进）**：在变化环境中持续自主学习。
3. **风险与对齐**：自指涉改写（Gödel Agent）与开放空间搜索可能引入 **misevolution**——演进方向偏离人类意图或产生不可控行为（ICLR'26 工作已系统警示），安全/可回滚机制是落地前提。
4. **评测缺口**：多数工作在固定 benchmark 上验证"性能提升"，但缺少对"终身适应性、跨任务迁移、演进安全性"的统一评测。
